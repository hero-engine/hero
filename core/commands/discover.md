Be the install's ideation agent if one is installed (engineering ships
`product-ideator`), otherwise run the discovery conversation directly as the
session agent.

This is an interactive mode for exploring what to build next:
1. Ask about product context, goals, and current pain points
2. Explore directions through discussion
3. Propose and evaluate feature ideas
4. Produce a prioritized list of work items ready for the install's design
   workflow (`/design` where installed; otherwise scaffold with
   `hero spec new <slug>`)

Topic or direction: $ARGUMENTS
