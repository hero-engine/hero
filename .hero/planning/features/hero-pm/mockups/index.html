Hero PM Domain Pack

Eight mockup surfaces

Layout locked · 2026-05-16 · Canonical preset: Horizon + Cycle (Shape Up, 6w) · 1440×900 ideal viewport

UX exploration for the Hero PM domain pack — the product-management surface that lives alongside Hero's engineering surface in the same workspace. Thesis: PMs and engineers work in one tool with two domain skins, joined by a visible cross-domain handoff edge.

The locked layout reflects two work modes. Housekeeping (artifact tabs active): left nav · tabbed center pane · artifact header chips + body · a bottom strip with state-aware action buttons + chat input · a right panel with sticky pinned ambient region at the top and a rolling chat scroll below. Design (Chat tab active): full center pane chat with hero-code chrome (provider/model picker, context fullness, attachments, mentions, slash, reasoning). No bottom strip on the Chat tab — the chat is the surface.

The bedrock distinction: bottom strip = verbs (user actions on the artifact). Sticky ambient = nouns / smarts (what the agent surfaces about the artifact). Header chips = identity / state. Agent-drafted content lands inline in the artifact with accept/edit/reject; the chat only logs the action.

The Hand off to /design button on Story detail is the platform thesis in one click. It lives inline-prominent in the artifact body next to the linked engineering feature card — not in the bottom strip. Purple (#7c3aed) is reserved exclusively for the cross-domain handoff edge.
