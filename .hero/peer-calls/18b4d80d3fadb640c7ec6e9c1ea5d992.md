- `SpecStore.swift` already implements the three-tier resolver
  described in the spec's Prerequisites: frontmatter `completed_at:`
  → `git log -1 --format=%aI -- <spec.md>` → file mtime, with
  `CompletedAtSource { frontmatter | git | mtime | none }` tracked
  per spec so the UI can downweight low-confidence values
  (SpecStore.swift:20-52, 193-286).
- Reader is **already tolerant of both `completed_at:` (snake_case)
  and `completedAt:` (camelCase)** — see SpecStore.swift:239-244.
  No change required to match the peer's writer contract.
- Velocity sparkline reads `completedAt` directly with no source-
  aware weighting (SpecStore.swift:747-753), so it will treat
  backfilled stamps and freshly-written stamps identically. That's
  the right shape for verification — the buckets will be stable
  across source transitions.
- SprintDashboardView consumes `completedAt` and downweights
  `mtime`-sourced values in display (SprintDashboardView.swift:407,
  412).
