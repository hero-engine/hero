Start a product discovery conversation using the `product-ideator` agent.

This is an interactive mode for exploring what to build next. The agent will:
1. Ask about product context, goals, and current pain points
2. Explore directions through discussion
3. Propose and evaluate feature ideas
4. Produce a prioritized list of work items ready for `/design`
