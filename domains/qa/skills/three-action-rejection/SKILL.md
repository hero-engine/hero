# Three-action rejection

Use Add AC when the committed intent is clear but underspecified. Use Suggest new
work when the finding is valuable and outside current scope. Use Reject as quality
issue when implementation contradicts existing acceptance criteria. Present the
source evidence, affected behavior, scope reasoning, and proposed text. Never use
rejection to smuggle new scope into delivery, and never auto-apply the decision.
