# Verdict output

Start with one clear recommendation: Approve, Changes Requested, Reject, Go,
Conditional Go, No-Go, or the domain-specific triage outcome. Follow with findings
ordered by consequence. Each finding includes evidence, affected behavior, why it
matters, confidence, and the smallest next action. Separate observed facts from
inference. Name missing evidence and leave accountable decisions to the human.
