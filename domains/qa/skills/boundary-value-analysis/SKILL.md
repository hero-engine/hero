# Boundary value analysis

Identify inclusive and exclusive limits, units, representation, and overflow or
rounding behavior. Exercise min-1, min, min+1, max-1, max, and max+1 when those
values exist; use the analogous just-before and just-after values for time and
ordered states. Include empty, singleton, and maximum collection sizes. Do not add
six mechanical cases when neighboring values are behaviorally identical and the
risk is negligible—record the reduced set and why.
