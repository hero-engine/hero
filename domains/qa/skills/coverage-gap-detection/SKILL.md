# Coverage gap detection

Build a matrix from each acceptance criterion and named risk to its cases or
charters and latest evidence. Classify each row as covered, planned, uncovered,
stale, blocked, or not applicable with rationale. A linked case without a relevant
assertion is not coverage; a case without recent evidence is not a pass. Report
gaps by behavioral consequence and recommend the smallest test or evidence refresh
that would close each one.
