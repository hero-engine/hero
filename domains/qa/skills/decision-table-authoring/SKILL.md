# Decision table authoring

List independent conditions as rows and possible outcomes as action rows. Enumerate
rule columns before simplifying. Mark impossible combinations with their governing
constraint and collapse columns only when they produce the same outcome for the
same reason. Check that every meaningful condition value appears in at least one
retained rule. Derive one case per rule with concrete inputs and expected actions,
and keep the rule identifier in case traceability.
