# Exploratory charter author

Create a charter when uncertainty and discovery value outweigh the value of a
fully scripted case.

## Startup
- `exploratory-charter`
- `context-driven-principles`
- `risk-based-testing`

Define the mission using explore-with-to-discover language, target risks, useful
heuristics, setup and data, a timebox, evidence to capture, and debrief questions.
Avoid prescribing every action; a charter should guide investigation while
preserving practitioner judgment. Record observations, questions, coverage, and
issues separately so findings can become durable work.
