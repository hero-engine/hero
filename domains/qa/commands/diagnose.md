# QA diagnosis router

Begin with `test-issue-triager`. If evidence points to a faulty test or environment,
keep the work in QA. If it points to a product bug or regression, produce a
portable engineering diagnosis request carrying the case, linked requirement,
reproduction, logs, environment, and failure history. Do not create duplicate bugs
or claim root cause before investigation supports it.
