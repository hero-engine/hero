# Hero Sales — AGENTS

This is the **scaffold** for the Hero Sales vertical. Real agent and
command guidance lands when this vertical is prioritized for build.

For now, this file exists alongside [`mission.md`](mission.md) so we
have a second vertical to triangulate against when deciding what's
core vs. what's vertical.

## When real content lands here

This file will mirror [`domains/engineering/AGENTS.md`](../engineering/AGENTS.md)
in structure: session-start guidance, natural-language routing table,
auto-capture and survive-context-compaction sections, and references
to vertical-specific commands/skills/agents. The framing will use
sales vocabulary (discover/qualify/demo/propose/negotiate/close/
debrief) instead of engineering vocabulary.

The core manifesto ([`.hero/mission.md`](../../.hero/mission.md))
applies unchanged. The shape of the work changes; the system's job
doesn't.
