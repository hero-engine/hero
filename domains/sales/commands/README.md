# Hero Sales — Commands

Slash commands for the Hero Sales domain pack.

| Command | File | What it does |
|---|---|---|
| `/qualify` | [qualify.md](qualify.md) | Run MEDDPICC qualification — score deal and write findings to spec |
| `/strategize` | [strategize.md](strategize.md) | Produce a full deal plan: approach, stakeholder map, objections, win criteria |
| `/forecast` | [forecast.md](forecast.md) | Weighted pipeline forecast grouped by stage, rep, and period |
| `/pipeline` | [pipeline.md](pipeline.md) | Kanban overview of open deals by stage with ARR totals |
| `/research` | [research.md](research.md) | Company intel, buyer research, competitive battlecards |
| `/debrief` | [debrief.md](debrief.md) | Win/loss analysis — capture learnings, update knowledge base |
| `/prospect` | [prospect.md](prospect.md) | ICP scoring, outreach strategy, discovery angle for new targets |

See [../AGENTS.md](../AGENTS.md) for the full routing table and natural-language
command routing. See [../mission.md](../mission.md) for the vertical charter.
