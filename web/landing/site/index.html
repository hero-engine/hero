The core loop

A small set of habits, captured as you go.

Hero is built around the spec lifecycle. Each step produces an artifact — a design, a diagnosis, a decision — that the next session can read.

01 · Discover

Surface what to build

Brainstorm, prioritize, shape rough ideas into candidate work items.

02 · Design

Spec before code

Goals, approach, and acceptance criteria — reviewed before anything is written.

03 · Deliver

Build from the spec

Implement, validate the acceptance criteria, capture learnings, and mark what shipped.

↳ Diagnose

When something breaks

Investigate root cause first; produce a fix spec; only then write code.

Natural language

You don't memorize commands.

Hero installs as slash commands inside your AI tool — /design, /diagnose, /deliver, and the rest. You can use them when you want to be explicit, but you don't have to. Just say what you want, and the model routes to the right workflow.

fix the login timeout bug → /diagnose
add CSV export to the reports page → /design
implement the auth spec → /deliver
put the checkout redesign on autopilot → /drive
review my PR → /review
what's blocking the billing migration? → asks the corpus
Why specs

Structure beats a 5000-line CLAUDE.md.

A flat file gets too short to be useful or too long to be afforded. Hero stores context as a structured corpus the model retrieves from on demand.

Design before you build

Goals, approach, and acceptance criteria in half a page of markdown. Misunderstandings get caught when they're cheap — not in code review.

Knowledge compounds

Specs, decisions, conventions, and attempts accumulate in .hero/. Models come and go; the corpus stays — committed to git, reviewable in PRs. Searched semantically with built-in inference — no API key, no network call, private by default.

Tool-agnostic

Claude Code, Cursor, OpenCode, Codex, Copilot — same corpus, same workflow. Switch harnesses without losing what your project has learned.

Ask why anything exists

hero why <thing> traces the chain of decisions and specs that led to it. hero blocked shows what's stuck and on what dependency. Real commands, today.

Get started

From install to first spec in three minutes.

Hero is a single Go binary. The corpus is plain markdown. Everything below can be copy-pasted into a real terminal.

Step 01

Install

Grab the binary for your platform.

$ brew install hero-engine/tap/hero
Step 02

Init & scan

Point Hero at a project. The first scan seeds the corpus.

$ hero init && hero scan
Step 03

Install in your AI tool

Translate Hero into your harness's format and start a session.

$ hero install project . --target claude
