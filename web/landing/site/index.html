Honest capability labels

Know what ships—and what setup it needs.

The public capability reference ties these labels to implementation evidence. Optional and preview surfaces keep their prerequisites beside the claim.

Shipped

Harness-native workflows

Hero installs into each supported target’s actual surfaces instead of assuming slash commands exist everywhere.

Requires: a supported install target and initialized Hero workspace.
Shipped

Local project intelligence

hero serve provides a local dashboard, API, MCP server, and watcher for registered projects.

Requires: deliberate local daemon startup; team or external access is separate.
Optional

Trackers and code hosts

Read evidence and perform bounded provider operations through configured integrations.

Requires: a supported connection, credentials, repository identity, and operation-specific consent.
Optional

Cross-repository peering

Keep one graph per project while using manifests, Project Mail, advisory calls, and explicit handoffs across repositories.

Requires: registered, reachable sibling repositories and peer manifests.
Preview

Headless agent runtime

Run provider-backed jobs with explicit budget and dry-run controls. Direct runner jobs and team queue jobs remain separate, with no shipped end-to-end approval pause/resume bridge.

Requires: model provider, credentials, execution environment, and release-level validation.
Planned

External spec providers

GitHub Spec Kit, OpenSpec, and other external spec systems are future direction—not shipped adapters.

Requires: a provider contract and at least two proven adapters.

Get started

Give your next coding session the project.

Install the prebuilt CLI, initialize one project-owned corpus, then render Hero into the coding harness you use. Replace codex with another supported target where needed.

1. Install

Use the Homebrew package on macOS or Linux.

brew install hero-engine/tap/hero

2. Initialize

Create the Hero workspace from your repository root.

hero init

3. Install workflows

Render the project’s workflows into your harness-native surface.

hero install project . --target codex
