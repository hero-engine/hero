# Hero v0.34.1 security patch

Hero v0.34.1 updates the release toolchain to Go 1.26.6 and
`golang.org/x/crypto` to v0.52.0. These updates remediate the reachable Go
standard-library vulnerabilities reported against the v0.34.0 binaries and
the published `golang.org/x/crypto` advisory affecting v0.50.0.

There are no intended Hero behavior, workspace-schema, configuration, or API
changes in this patch release. Existing v0.34.0 workspaces can replace the
binary in place. As a post-upgrade check, run `hero version`, `hero doctor`,
and `hero check`.

Release publication must use the immutable `v0.34.1` tag. The v0.34.0 tag and
artifacts remain unchanged for traceability; rollback restores the v0.34.0
package metadata and binaries while a subsequent patch is prepared.
